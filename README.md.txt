# Pinnacle Cybersecurity Internship

This repository documents the tasks completed during the Pinnacle Labs Cybersecurity Internship.  
The internship focused on practical implementation of encryption techniques and security utilities.

---

## 📌 Internship Overview

- **Organization:** Pinnacle Labs  
- **Role:** Cybersecurity Intern  
- **Focus Area:** Encryption & Security Tools  
- **Mode:** Practical Project-Based Internship  

---

## 🛠 Tasks Completed

### 🔐 Task 1 – Text Encryption
Developed a tool to encrypt and decrypt text using standard cryptographic algorithms.

**Concepts Covered:**
- Encryption algorithms
- Data confidentiality
- Secure text handling

---

### 🖼 Task 2 – Image Encryption
Created a system to encrypt image files to protect visual data from unauthorized access.

**Concepts Covered:**
- File handling
- Binary data encryption
- Secure image storage

---

### 🔑 Task 3 – Password Analyzer
Built a utility to evaluate password strength and identify security weaknesses.

**Concepts Covered:**
- Password validation logic
- Security best practices
- Strength evaluation techniques
